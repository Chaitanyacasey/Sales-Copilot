# ⚡ Sales Copilot

> Simple Open-Source RAG Assistant for Real Estate Sales Calls.

---

## 📌 Features

- **💬 Live Copilot:** Select a buyer lead, type notes, and instantly retrieve buyer motivations, pitch cues, and matching property listings.
- **📋 Call Briefs:** View scheduled lead call briefs with interaction history.
- **🏡 Listings Database:** Search and filter property listings by zoning, city, and cap rate.

---

## 🚀 Quick Start

```bash
# Navigate to project
cd Sales-Copilot

# Install requirements
pip install -r requirements.txt

# Run app
streamlit run app.py
```

Access the app at `http://localhost:8501`.
